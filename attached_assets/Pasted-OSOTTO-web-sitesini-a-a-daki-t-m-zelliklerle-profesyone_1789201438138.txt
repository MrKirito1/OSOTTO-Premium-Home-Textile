2. SAYFA YENİLENDİĞİNDE EN ÜSTTEN BAŞLASIN
==================================================

Şu anda kullanıcı sayfanın aşağısındayken F5 / refresh yaptığında sayfa eski scroll konumunda kalıyor.

BUNU DÜZELT.

Sayfa her yenilendiğinde EN ÜSTTEN başlamalı.

Browser scroll restoration özelliğini manuel kontrol et.

Gerekirse:

if ("scrollRestoration" in history) {
    history.scrollRestoration = "manual";
}

kullan.

Sayfa ilk mount olduğunda:

window.scrollTo({
    top: 0,
    left: 0,
    behavior: "instant"
});

uygula.

Ancak kullanıcı normal şekilde bir bölüme tıkladığında smooth scroll çalışmaya devam etmeli.

Örneğin:

KOLEKSİYON → Koleksiyon bölümüne smooth scroll

TEKLİF ALIN → Teklif bölümüne smooth scroll

BAYİMİZ OLUN → Bayi başvuru bölümüne smooth scroll
